# 演示脚本

这是录制 Nihonco 展示视频用的自动操作脚本，**只控制应用界面，不负责录屏**。

## 运行

```bash
npm run demo
```

应用启动后，窗口会出现快捷键提示：

```text
Control + Shift + D
```

先开始 macOS 系统录屏（选 Nihonco 窗口、麦克风 BlackHole 2ch），再点一下 Nihonco 窗口，按这个快捷键。

## 流程

```text
会话 → 解说 → 单词 → 例句
→ 单词复习/退出/新規
→ 例句复习/退出/新規
→ 中文翻译测试
```

开头会快速过一遍模式、等级、复习、新規提示音；正式流程前在解说模式停 12 秒。

脚本不修改学习数据以外的应用配置，也不启动或停止录屏。
